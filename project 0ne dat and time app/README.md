# Date & Time Android Application

Simple Android app that displays the current date and time in real time.

Features:
- Shows current date (day, month, year)
- Shows current time (hours, minutes, seconds)
- Updates every second

Build via GitHub Actions: see `.github/workflows/build.yml` which runs `./gradlew assembleDebug`.

Notes:
- This repository contains a minimal Java-based Android app. Add the Gradle wrapper files (`gradlew`, `gradlew.bat`, and the `gradle` directory) if you want to build locally using `./gradlew`.
